# 小小遊戲樂園

給小朋友玩的無廣告小遊戲合集，共 23 款原創遊戲，以 iPad 觸控為主，舊款 iPad 也能順跑。

- 沒有廣告、沒有追蹤、沒有外部連結；遊戲紀錄只存在裝置本機
- 第一次開啟後會離線快取，沒有網路也能玩
- 已設定 `noindex`，不會被搜尋引擎收錄

## 遊戲清單

| 類別 | 遊戲 |
|---|---|
| 益智動腦 | 2048、寶石消消樂、方塊堆疊、動物翻翻樂、踩地雷、泡泡龍 |
| 動作反應 | 恐龍世界（3D）、貪食蛇、打磚塊、跳跳大冒險、太空射擊、敲敲地鼠、飛飛小飛機、跳跳兔、小朋友下樓梯（1～4 人） |
| 競速運動 | 公路賽車、投籃高手、點球大戰、釣魚樂 |
| 雙人對戰（也可對電腦） | 桌上冰球、五子棋、坦克對戰、四子棋 |

每款都有簡單（4–6 歲）／普通（7–9 歲）／困難（10–12 歲），雙人遊戲為雙人或對電腦。

### 關卡與難度

每款遊戲都會隨時間或關卡逐步變難，並陸續出現新的障礙和獎勵，升關時遊戲會先停 3 秒（倒數 3、2、1），畫面出現「第 N 關」橫幅說明這一關多了什麼，看清楚再繼續。
益智類是一關一關過（盤面變大、出現石頭／冰塊等障礙、炸彈／星星等獎勵）；雙人類是比賽中途加入道具與障礙，對電腦時電腦每輸一次就變強。

### 小朋友下樓梯

1～4 人同一台 iPad 一起玩（建議橫放、大家坐同一邊），每人一組自己顏色的 ← → 鍵。站在不斷上升的樓梯上往下走，避開天花板尖刺與尖刺樓梯；
越往下會出現輸送帶、彈簧、會翻的樓梯，以及愛心與無敵星星。多人時最後還活著的人獲勝。

### 恐龍世界（3D）

選一隻恐龍（暴龍、迅猛龍、副櫛龍、劍龍、三角龍、雷龍），在叢林小島吃東西、喝水、躲開肉食恐龍，從寶寶長大成首領。
四關＝四個成長階段（寶寶→少年→成年→首領）：第 2 關迅猛龍出沒、出現金色果子／金色大肉；第 3 關暴龍和刺刺草叢、可以找恐龍蛋；第 4 關天黑、火山會噴石頭（地上先出現紅圈）、出現首領之星。
被打倒只是「暈倒」，會回到恐龍巢休息（共 3 條命）；恐龍巢是安全區，肉食恐龍進不來。草食龍吃果子，肉食龍吃肉和抓魚，不血腥。
左下搖桿走路，右下三顆鈕：攻擊（咬／甩尾／衝撞／大叫）、跳、吃／喝（附近有東西時會變大發亮）。簡單模式站在食物或水旁邊就會自動吃喝。

### 可愛動物角色與身體律動

主角兔兔與各遊戲的小動物（地鼠、金倉鼠、企鵝守門員、章魚、草帽貓咪、刺蝟、青蛙、小鳥、小蜜蜂、胖麻雀，以及泡泡裡的小動物、企鵝／狐狸棋子）都是原創繪製。
會動的角色拆成部件（`assets/rig/`、`js/rigs.js`），由 `js/rig.js` 每一格即時擺動作：走路雙腳交叉、先蹲再跳、落地壓扁、被打到後仰閃白再晃回來、暈眩、開心慶祝、拍翅。
部件圖由 scratchpad 的 `rig_export.py` 產生；`tools/rig_preview.html` 可以播放所有角色的動作。

### 操作方式

- 需要控制方向的遊戲（恐龍世界、貪食蛇、坦克對戰、跳跳兔）用固定式萬向搖桿
- 方塊堆疊用十字方向鍵（↑ 旋轉、← → 移動、↓ 加速）加一顆「落下」大圓鈕
- 每款開局都有手套動畫示範怎麼操作，開始畫面也有操作圖解

### 太空射擊武器

6 種武器，每種 Lv1–Lv5：雷射連射、散彈、追蹤飛彈、貫穿光束、閃電鏈、護衛僚機。
撿到同一種武器寶石升 1 級，撿到不同種就換武器但保留等級；被打中降 1 級。另有清空全畫面的炸彈。

## 在 iPad 上使用

用 Safari 開啟網址 →「分享」→「加入主畫面」，之後就像 App 一樣全螢幕開啟。

## 技術說明

- 純 HTML + Canvas 2D + 原生 JavaScript（ES2017），不需要任何建置工具
- `js/engine.js`：共用引擎（迴圈、觸控、選單、音效合成、圖片載入）
- `js/games/<遊戲>.js`：各遊戲
- 恐龍世界用 three.js r128（`js/lib/three.min.js`，MIT 授權）畫 3D；恐龍是程式依真實比例「雕」出來的（`js/dino/sculpt.js`），動作每一格即時擺骨頭（`js/dino/anim.js`：走路雙腳交替、先蹲再跳、落地壓扁、被打後仰晃動、低頭吃喝、暈倒趴下）
- `assets/`：圖片素材（已壓縮）；`assets/covers/` 是首頁與開始畫面用的遊戲封面插畫（以 Kenney 素材合成）
- 效能：靜態背景畫在背景圖層、捲動背景用 CSS 位移、外框字快取、棋盤類懶惰重繪，並會依裝置順暢度自動降低解析度
- `sw.js`：離線快取。修改任何檔案後執行 `python tools/gen_sw.py` 更新版本號，iPad 才會抓到新版

本機測試：在此資料夾執行 `python -m http.server`，再用瀏覽器開 `http://localhost:8000`。
